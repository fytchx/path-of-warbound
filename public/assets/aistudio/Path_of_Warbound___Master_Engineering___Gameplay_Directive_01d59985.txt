PATH OF WARBOUND — MASTER ENGINEERING & GAMEPLAY DIRECTIVE
Complete End-to-End Specification for a Cohesive, Responsive, and Deeply Playable Release.


Purpose: This document defines the complete gameplay experience, mathematical engine, data contracts, pacing numbers, and mobile-portrait UI standards for Path of Warbound. Rather than dripping features out in fragmented micro-versions, build the entire cohesive core game cleanly so every system works together seamlessly from first boot.

1. VISION, DESIGN PHILOSOPHY & HARD GUARDRAILS
What Makes Path of Warbound Enjoyable
* Core Identity: "An intimidating monster in the background, simple for a solo developer to build without scope creep, deeply stimulating for theorycrafters, and effortless for the average player."
* Soul-Spark Identity: There is no physical character body, portrait, or rigid class selection. The player is a disembodied Soul-Spark bound directly into Warbound Armaments. Equipped gear, linked gems, and the passive constellation define the character.
* Zero Human Faces: Never render human faces or character portraits anywhere in art or UI. The header emblem always displays fx_soulspark inside the #w-medal SVG frame.
* Quiet, Self-Explanatory UI: Do NOT lock tabs, hide core buttons behind multi-step scripted tutorials, or spam popup banners/whispers. Every screen and control must be immediately accessible, uncluttered, and self-explanatory through clean labels, clear visual feedback, and tap-to-inspect cards.
Mandatory Repository & Engineering Guardrails
* Never Commit or Push Automatically: Never run git commit, git push, git merge, git rebase, or git reset --hard without explicit user approval. Stop and present a complete file summary when finished.
* Never Modify Art Assets: Never edit, overwrite, or regenerate files inside assets/ or warbound-sprite.svg. assets/manifest.json is the single source of truth; reference all art by manifest ID (AssetId), never hardcoded paths.
* Clean Architecture Separation:
   * src/engine/ must remain 100% pure TypeScript with zero DOM, window, document, or CSS dependencies.
   * src/data/ holds all game definitions and tuning values in validated JSON registries.
   * src/game/ manages state, inventory, crafting, gem socketing, and local persistence.
   * src/ui/ renders the 390px mobile-portrait interface using Vanilla TypeScript and warbound-sprite.svg.

3. COMPLETE MATHEMATICAL & COMBAT ENGINE SPECIFICATION
3.1 The 4 Core Attributes
Each core attribute maps to exactly four distinct, non-overlapping mechanic vectors:


* Might (attr_might):
   1. Weapon Base Damage (scales physical and weapon-based hits).
   2. Ability Power (flat and percentage scaling on offensive skills).
   3. Critical Strike Multiplier (+0.5% per point of Might).
   4. Armor Break (ignores a percentage of enemy Armor).
* Agility (attr_agility):
   1. Attack Speed (faster weapon auto-attacks and physical attack skills).
   2. Double-Hit Chance (chance for hits to echo immediately at 70% damage).
   3. DoT Tick Speed (accelerates Bleed, Ignite, and Corruption tick frequency).
   4. Dodge Rating (feeds entropy-assisted evasion).
* Wisdom (attr_wisdom):
   1. Cast & Channeling Speed (faster spell execution and channeling rates).
   2. Max Mana & Mana Regen (sustains high-frequency multi-skill rotations).
   3. Max Ward (recharging magical barrier absorbing damage before Health).
   4. Ailment Potency (amplifies damage and debuff magnitude across all 5 ailments).
* Fortitude (attr_fortitude):
   1. Max Health (expands base life pool).
   2. Auto-Heal / HP Regen (flat and percentage life restored per second).
   3. Armor (mitigates incoming physical and hit-based damage).
   4. Thorns (reflects scaled damage back to attackers upon taking a hit).
3.2 The 5 Damage Schools & Signature Ailments

1. Physical (school_physical) $\rightarrow$ Bleed (ailment_bleed): Stacking physical Damage over Time.
2. Fire (school_fire) $\rightarrow$ Ignite (ailment_ignite): High-magnitude single-instance burning DoT.
3. Frost (school_frost) $\rightarrow$ Chill / Freeze (ailment_chill): Slows enemy attack/cast speed; freezes enemy action bar entirely at maximum Chill stacks.
4. Lightning (school_lightning) $\rightarrow$ Shock (ailment_shock): Target takes +10% to +40% increased damage from all sources based on hit severity $\times$ Wisdom Potency.
5. Void (school_void) $\rightarrow$ Corruption (ailment_corruption): Chaos/Void DoT that bypasses standard Armor and reduces enemy healing and Ward recharge rate by 35%.
3.3 Master Stat Aggregation & Two-Pass DAG Conversions
Stats recompute from scratch as a pure function of equipped gear, socketed gems, allocated tree nodes, and active temporary buffs using a 4-layer resolution pipeline:


$$\text{Final}(X) = \left( \text{Base}(X) + \sum \text{Flat}(X) \right) \times \left( 1 + \frac{\sum \text{Increased}%(X)}{100} \right) \times \prod \left( 1 + \frac{\text{More}%(X)}{100} \right)$$


* Increased Pool: Additive sum from gear affixes, minor tree nodes, and basic passives.
* More Pool: Multiplicative product from Support Gems, Keystones, and active Combat Doctrines.
Two-Pass Forward-Only Conversions (Cycle-Free Directed Acyclic Graphs)
* Pass 1 (Attributes & Defenses):
$$\text{Might} \longrightarrow \text{Agility} \longrightarrow \text{Wisdom} \longrightarrow \text{Fortitude}$$
$$\text{Armor} \longrightarrow \text{Max Ward} \longrightarrow \text{Dodge Rating}$$
* Pass 2 (Damage Schools):
$$\text{Physical} \longrightarrow \text{Fire} \longrightarrow \text{Frost} \longrightarrow \text{Lightning} \longrightarrow \text{Void}$$
3.4 Combat Damage, Defense & Ailment Formulas
   * Raw Hit Roll:
$$\text{RawHit} = \text{RandomRange}(\text{Dmg}{\min}, \text{Dmg}{\max}) \times \text{SkillEffectiveness} \times \left(1 + \frac{\text{Might}}{100}\right) + \text{AP}_{\text{Scaling}}$$
   * Critical Strike Roll:
$$\text{CritHit} = \text{RawHit} \times \left(1.50 + \text{BonusCritMulti} + \frac{\text{Might}}{200}\right) \quad \text{when } \text{Roll} \le \min(1.0, \text{CritChance})$$
   * Agility Double-Hit:
$$\text{DoubleHitChance} = \min\left(0.75, \frac{\text{Agility}}{\text{Agility} + 250}\right)$$
On proc, the hit echoes immediately at 70% damage, triggering all on-hit effects and ailment rolls.
   * Entropy-Assisted Dodge:
Maintain entropyCounter (initial 0). Each incoming hit adds $\text{DodgeChance} \in [0, 75]$. When $\text{entropyCounter} \ge 100$, hit is Dodged and $\text{entropyCounter} \gets \text{entropyCounter} - 100$.
   * Armor Mitigation (vs. Enemy Level $L$):
$$\text{ArmorDR} = \min\left(0.80, \frac{\text{Armor}}{\text{Armor} + 45 \times L}\right)$$
   * Soft-Punishment Elemental & Void Resistances:
$$\text{DamageAfterRes} = \text{IncomingDamage} \times \left(1 - 0.80 \times \min\left(0.75, \text{Resistance}\right)\right)$$
   * Ward Barrier Mechanics:
Absorbs post-mitigation damage prior to Health. Recharges after 2.0s without damage (reduced by Wisdom), recovering 20% Max Ward/sec.
   * Anti-Double-Dipping Ailment DoT Formula:
$$\text{DoT_DPS} = \text{BaseAilmentDamage} \times \left(1 + \frac{\text{Wisdom}}{120}\right) \times \left(1 + \frac{\text{Agility}}{150}\right)$$
   * Item Gearscore Calculation:
$$\text{Gearscore} = (\text{ItemLevel} \times 10) + \sum (\text{AffixTier} \times 15) + (\text{LinkedSockets} \times 25)$$
3.5 Four-Tier Execution Engine & Dynamic Utility Score ($S_i$)
Every tick (100ms), the combat engine processes four execution tiers:


      1. Tier 1 — Persistent Reservations: Auras and Heralds reserve Max Mana percentage before combat starts.
      2. Tier 2 — Instant Cooldown Automation: Zero-cast-time buffs and warcries execute instantly off cooldown.
      3. Tier 3 — Event & Energy Triggers: Triggers (on_crit, on_damage_taken, on_hit, energy_full) fire linked skills asynchronously. Snake-order tie-breaker: Socket $1 \rightarrow 2 \rightarrow 4 \rightarrow 3 \rightarrow 5 \rightarrow 6$ across slot hierarchy: Chest $\rightarrow$ Ring 1 $\rightarrow$ Main Hand $\rightarrow$ Ring 2 $\rightarrow$ Offhand $\rightarrow$ Helmet $\rightarrow$ Amulet $\rightarrow$ Gloves $\rightarrow$ Boots $\rightarrow$ Legs $\rightarrow$ Trinket.
      4. Tier 4 — Active Cast Loop ($S_i$ Evaluation):
Calculates score $S_i$ for every ready, mana-affordable Active Gem $i$ on the active bar:


$$S_i = (B_i \times U_i \times M_{\text{econ}} \times M_{\text{synergy}} \times W_{\text{doctrine}}) - C_{\text{waste}}$$


         * $B_i$ (Base Role Weight): Emergency Recovery (95) > Curse/Exposure/Mark (85) > Offensive Buff/Warcry (80) > Cooldown Nuke (75) > Primary Clear/Filler (55).
         * $U_i$ (Urgency, $0.05 \text{ to } 3.0$): $1.2$ if debuff missing or $<1.5\text{s}$ left ($0.05$ if active); $+0.25$ per extra live enemy for AoE; $+0.60$ vs Bosses for single-target; scales as EHP drops.
         * $M_{\text{econ}}$ (Resource Lookahead, $0.2 \text{ to } 1.2$): Drops to $0.25$ on filler skills if spending Mana starves a higher-priority skill coming off cooldown within $1.2\text{s}$.
         * $M_{\text{synergy}}$ (Combo Multiplier, $1.0 \text{ to } 2.0$): Boosts payoff skills (+30% to +80%) when target exhibits Exposure, Shock, Freeze, or Corruption.
         * $W_{\text{doctrine}}$ (Playstyle Weight, $0.0 \text{ to } 2.5$): Driven by selected Combat Doctrine.
         * $C_{\text{waste}}$ (Overkill Penalty, $0 \text{ to } 150$): Deducts up to 80 points if a nuke's minimum damage exceeds target remaining HP by $>200%$; deducts points if boss windup will land before animation finishes.
3.6 The 5 Combat Doctrines (doctrine_*)
         * Tactician (doctrine_tactician): Balanced AoE and single-target prioritization. Triggers defensive Guard skills when HP drops below 45%.
         * Blitz (doctrine_blitz): Heavy offensive bias. Front-loads damage buffs; delays Guards until $<20%$ HP; ignores animation penalties. Perk: +15% Attack/Cast Speed for 3s after killing an enemy.
         * Bastion (doctrine_bastion): Defensive and predictive logic. Casts Guards at 75% HP or during enemy telegraph windups. Perk: +25% Defensive Cooldown Recovery; blocked hits restore 5% Max Mana.
         * Weaver (doctrine_weaver): Debuff and DoT optimization. Suppresses DoT payoff skills ($0.2\times$) until Curses/Exposure are active. Perk: +20% ailment damage against targets with $\ge 3$ active debuffs.
         * Entropy (doctrine_entropy): High variance engine. Locks $M_{\text{econ}} = 1.0$ and applies $\pm 35%$ random noise to $S_i$ each tick. Perk: Triggered skills have a 20% chance to ignore internal cooldowns and double-cast at $0.7\times \text{–} 1.6\times$ power.

6. ZONE PACING, RIFT KEYS & OFFLINE PROGRESSION
         * 3 Zones (10 Tiers each): Ashen Graveyard (bg_ashen_graveyard), Ember Canyon (bg_ember_canyon), Frozen Cathedral (bg_frozen_cathedral).
         * Pack Size Slider (1 to 5): Direct control over active monster spawns (1–5). Each slot rolls independently for Elite status ($p_{\text{elite}}$ scaling from $0.12$ to $0.20$, enabling rare 5-Elite waves at $p_{\text{elite}}^5$).
         * Rift Keys & Boss Mechanics: Zone enemies drop key_rift. Collecting 3 keys enables the "Summon Zone Boss" action (extra keys can be banked for consecutive runs). Defeating a Zone Boss unlocks the next Tier; dying drops player back 1 Tier (minimum Tier 1).
         * Tier 1 $\rightarrow$ Tier 2 Target Metrics:
         * Tier 1 Normal Mobs: ~75 HP, ~7 DPS, 22 XP (~3.5s kill time with starter weapon; 10–12 kills to reach Level 2).
         * Tier 1 Zone Boss: ~850 HP, ~24 DPS with telegraphed slam every 4.5s (requires 2–3 drops, 1 linked support, and +2 weapon upgrade).
         * Tier 2 Normal Mobs: ~190 HP, ~18 DPS, 48 XP.
         * Offline Farming Engine: Calculates offline time (capped at 8 hours) against active zone, tier, and pack size. Awards accumulated XP, Gold, and materials without triggering new Zone Boss encounters.

8. DEFINITION OF DONE & VERIFICATION GATE
The build is complete only when all of the following verification checks pass:


         1. Asset & Stat Validation: npm run validate executes with 0 missing AssetId references in assets/manifest.json and 0 invalid stat keys.
         2. Automated Unit Testing: npm test passes all unit tests covering multi-skill rotation priority, two-pass DAG conversions, ailment math, radial tree BFS/Tarjan refunds, and save persistence.
         3. Balance Simulation: npm run sim executes 10,000 engine ticks across 4 distinct builds and outputs balanced DPS, Kills/Hr, and Rift Keys/Hr metrics.
         4. TypeScript Build: npm run build compiles cleanly without TypeScript errors or warnings.
         5. Runtime UX Audit: In a fresh 390px browser session:
         * Progress bars move deterministically without backward snapping.
         * Starter inventory is pristine (1 weapon equipped, 0 clutter).
         * Reaching Level 2 requires ~40–50 seconds of active combat.
         * Every gem renders a plain-English inspect description modal.
         * Socketed skills execute in priority sequence.
         6. Execution Protocol: STOP before any git commit or git push and present a full summary of modified/created files for approval.
